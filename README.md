### 📂 Contenido del Repositorio

Aquí encontrarás mis apuntes, infografías y reportes organizados por tema. Haz clic en el botón de cada uno para ver el documento en PDF:

*   **Fundamentos de BD:** Infografía sobre qué es una base de datos, su importancia y sus componentes principales (tablas, claves, relaciones).
    <br><a href="Conceptos_Basicos_BD.pdf"><img src="https://img.shields.io/badge/📄_Ver_Conceptos_Básicos-blue?style=flat" alt="Ver PDF" /></a>

*   **Evolución Histórica:** Línea del tiempo desde el modelo jerárquico hasta el auge del Machine Learning y bases NoSQL.
    <br><a href="Linea_del_Tiempo_BD.pdf"><img src="https://img.shields.io/badge/📄_Ver_Línea_del_Tiempo-blue?style=flat" alt="Ver PDF" /></a>

*   **Gestión de la Información:** Resumen visual de las etapas del proceso de curación de datos (adquisición, diseño, validación y mantenimiento).
    <br><a href="Curacion_de_Datos.pdf"><img src="https://img.shields.io/badge/📄_Ver_Curación_de_Datos-blue?style=flat" alt="Ver PDF" /></a>

*   **Estructura y Diseño:** Reporte detallado sobre el Modelo Relacional, el Modelo Entidad-Relación (E-R) y la transformación entre ambos.
    <br><a href="Reporte_Modelado_Datos.pdf"><img src="https://img.shields.io/badge/📄_Ver_Reporte_Modelado-blue?style=flat" alt="Ver PDF" /></a>

*   **Relaciones:** Infografía explicativa sobre las relaciones 1:1, 1:N y N:N, junto con conceptos clave de integridad referencial.
    <br><a href="Infografia_Cardinalidad.pdf"><img src="https://img.shields.io/badge/📄_Ver_Cardinalidad-blue?style=flat" alt="Ver PDF" /></a>

*   **Entorno de Trabajo:** Guía paso a paso sobre la instalación, configuración del servidor y creación de la primera base de datos.
    <br><a href="Instalacion_MariaDB_HeidiSQL.pdf"><img src="https://img.shields.io/badge/📄_Ver_Instalación-blue?style=flat" alt="Ver PDF" /></a>
